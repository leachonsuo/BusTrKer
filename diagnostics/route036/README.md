2026-10-11 로컬 Functions Emulator에서 노선 상세·형상·경유 정류장을 각 한 번 조회했다. 실제 routeId는 `241293003`, 표시 번호는 앞자리 0을 포함한 `036`, 유형은 마을버스다. 상세의 기점은 더퍼스트프라임, 종점은 오미산주유소다. 기존 함수의 최초 실패 조건은 `splitRouteDirections()`의 `AMBIGUOUS_TURN_MATCH`다. 공식 `turnYn=true` 방문은 35번, ID `219000101`(오미산주유소) 하나다. 형상 인덱스 `368.990`은 이 정류장으로부터 4.04m, `383.437`은 11.54m다. 형상 진행 거리상 두 후보는 약 721m 떨어진다. 직전 34번 정류장은 인덱스 `361`, 직후 36번 정류장(ID `219000237`)은 인덱스 `369.443`(17.27m) 또는 `382.959`(9.73m)에 대응할 수 있다.

전체 방문 순서를 함께 검증하면 경계 `369`에서는 두 방향 모두 완전한 증가 순서 후보 조합이 있다. 경계 `384`에서는 복귀 첫 방문인 36번 정류장의 가장 가까운 형상 지점조차 125.85m 떨어진다. 기존 35m 한계를 그대로 적용하면 두 번째 회차 후보는 배제된다. 공통 알고리즘은 이제 **전체 방문 순서와 거리 기준을 모두 통과한 회차 방문 그룹이 정확히 하나일 때만** 방향을 분리한다. 이 fixture에서는 정류장 범위 `1–35` / `35–69`, 형상 범위 `0–369` / `369–751`이다. 좌표를 이동하거나 가상의 구간을 만들지 않았다.
